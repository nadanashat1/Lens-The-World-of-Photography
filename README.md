# Lens - The World of Photography (عدسة)

An Arabic-language photography blog built with React and Vite. It presents photography articles with featured posts, category filtering, and search, all rendered from a local content file.

## Features

- Home page with featured and latest posts
- Blog listing with live search across titles and content, plus category filtering
- Individual article pages routed by slug
- About page and a custom 404 page
- Fully Arabic (RTL) content and interface

## Tech stack

- React 18, React Router
- Vite
- Plain CSS per page

## Getting started

```bash
npm install
npm run dev
```
